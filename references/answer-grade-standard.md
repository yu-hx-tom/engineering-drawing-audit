# 答案级审核报告标准（从 5 份答案报告提炼）

> 来源：780314、780672、780673、780674、860404 五份答案级审核报告（2026-08-11 分析）
> 用途：engineering-drawing-audit 报告必须达到的标准，替代"尺寸列表"式简化报告。

## 1. 报告结构（必含）

1. **审核范围**节：声明客户原图/重绘图文件、审核对象（所有带尺寸视图）、状态分类含义。不纳入标题栏/材料/技术要求文字对照。
2. **结论摘要**：客户共识别 N 个带尺寸视图、M 项标注，按状态分类统计。
3. **按客户视图分节**（V1 主剖视、V2 俯视、V3 局部放大、V4 B-B 剖面...），每节先给"视图映射说明"表。
4. **每尺寸一行**：ID(V1-D01) | 客户标注 | 所控制的物理特征 | 重绘视图/位置 | 重绘标注 | 状态 | 问题证据/备注。
5. **每视图"小结"**段。
6. **重绘新增/未按原式表达**专节。
7. **尺寸核销汇总**：各状态数量，合计=总数。
8. **结论与建议**：优先处理项、参考属性按企业习惯决定。

## 2. 状态 6 类（严格）

| 状态 | 含义 |
|---|---|
| Match | 同一物理特征，完整标注一致 |
| Equivalent expression | 信息保留，视图/位置/制图表达不同（对称、尺寸链、分数转换、文字改截面、典型展开）|
| Difference to note | 参考属性移除/小数值变化，数值实质一致，不判错误 |
| 存在差异 | 同一特征数值/几何一致，但属性被省略（**特指 Tip. 典型标记省略**，780673 答案用词）；比 Difference to note 更明确指向属性缺失 |
| Confirmed error | 同一特征，数值/符号/公差/参考属性明确冲突 |
| Confirmed omission | 客户标注存在，重绘无等价表达 |
| Needs manual confirmation | 扫描字符不足，不能唯一结论 |

**属性省略状态口径（2026-08-12 从 780673 提炼）**：
- 客户 **Tip.(典型)** 属性被省略 → **存在差异**（数值同也判，780673 五例）。
- 客户 **Ref./括号** 参考属性被移除 → **Difference to note**（数值同，780673 六例）。
- Tip. 省略但重绘有显式替代表达（18槽均布/两处 R5）→ **等价表达**。

## 3. 物理特征判断（核心）

- 每个尺寸必须给出**具体物理特征名称**，依据**尺寸界线端点/引出线/尺寸线形状**判断。
- 禁止用"长度/直径"泛称。案例："波形法兰斜边长度""顶部法兰最大外径""主外锥面基准"。
- **同值不同特征分开核销**：数值相同但端点/方向不同的尺寸分别记录。

## 4. 必须捕获的标注类型

1. 尺寸（线性/直径/半径/角度/弧长），含 Ø/R/°分秒 符号
2. 公差（尺寸 +0.2/0、角度 ±5'、双向 +7/-5）
3. 参考尺寸（REF/星号*/括号()），**属性必须核对**
4. 基准符号（基准 A/B）
5. 几何公差（同轴度 ◎AØ3、全跳动、位置度）
6. 表面粗糙度（Ra 值）
7. 数量（2-Ø40、6×、8X、Tip 典型）
8. 图案/技术说明（槽宽、槽深、阵列间距）

## 5. 常见漏判清单（RED 阶段提炼）

1. **漏判 omission**：客户独立标注重绘无，不能拿相似值顶替（Ø1515 vs Ø1460）。
2. **漏判参考角度**：参考角度（60°*）重绘无，需确认 omission。
3. **状态判定过弱**：名义值+公差+参考属性都变 = Confirmed error，不是"需人工确认"。
4. **漏判数值差异**：420 vs 419.1 = Confirmed error。
5. **漏判局部视图 omission**：局部放大图的尺寸（凸块 22、肩部 5）逐一核对。
6. **参考属性漏核**：* / Ref / 括号移除是 error 或 difference。
7. **数量核销不精确**：状态合计必须=客户总数。
8. **未查重绘新增标注**：重绘新增/合并标注专节列出。
9. **漏判参考直径 omission**：客户参考直径（Ø276.9 Ref、Ø553.7 Ref）重绘无 = Confirmed omission。
10. **漏判几何公差**：同轴度/跳动/位置度及基准。
11. **多形位公差框并存漏判**：全跳动与同轴度/同心度同时存在时只列一个（780314：GLM 捕获全跳动 1.5\|A 却漏同轴度 ◎Ø3\|B）。
12. **附加视图单标注漏判**：侧视/向视/局部放大视图只有 1 个标注（如参考尺寸）时整节被丢（780314：上口侧视图 17 REF 被并入主视图而丢失）。
13. **粗糙度逐处计数漏判**：相同 Ra 值出现在多个表面只计一处（780314：Ra 12.5 应为下部外锥面+底部斜端面两处）。**反向风险：计数指令易致臆造**——只认实际画出的粗糙度符号，禁止凭对称性把表面逐一填上 Ra（780314：GLM 曾从 2 处臆造到 8 处）。
14. **臆造标注**：GLM 自由读把小/模糊标记编成数值（780314：40.2←40+0/-2、55.5←555±2、51.5°←51°50′、假基准"2"、假 R10.5），必须经尺寸表核销过滤。
15. **重绘尺寸表漏条目被误判为"重绘无"**：build_dim_table 的底部 y 固定截止把俯视图下部尺寸当标题栏丢弃（780672：254/190/125.2 及 10°±5′ 全丢）。"重绘无 X" 前必须同时查 dim-table 与重绘 GLM 视觉读，排除尺寸表过滤造成的假缺失。
16. **低清扫描件自由读臆造**：≤200dpi 扫描上 GLM 臆造大量数值（780672：765←745、48×10.5、6×R25、多处 √Ra12.5）。自由读只作候选，客户读数须以重绘尺寸表核销 + 裁剪放大核验；客户独有值（Ø1515、60°*、22/5）必须裁剪核验后才可入报告。
17. **基准符号臆造**：剖视/向视图名称字母（A-A/B-B）、中心线被误读为基准（780672 假基准A/B；780314 假基准"2"）。基准必须看到三角形基准符号+字母，否则写"无基准"。
18. **高密图纸整图读退化重复**：GLM 全图单次读在高标注密度图纸上陷入重复输出循环（780673：第 25 项后刷屏重复，后续视图全漏）。必须 2×2/按视图边界分块重读再合并；分块后同轴度框（◎AØ3/◎BØ3）、基准、参考尺寸反而更易读出。
19. **Tip. 省略 ≠ Ref./括号移除**：客户 Tip.(典型) 属性被省略（数值同）判"存在差异"（780673 五例：Ø60 Tip./R200 Tip./R10 Tip./40° Tip./40 Tip）；Ref./括号参考属性被移除判 Difference to note（六例）。重绘以显式替代表达（18槽均布、两处 R5）时 Tip. 省略判等价表达。
20. **公差归属被对角线主值抢走**：公差片段与主值的归属不能只按欧氏最近——CAD 公差紧跟所修饰值右侧同行（`1070 ±7.5`），右侧下方/上方的别的主值（`R10 TYP`）欧氏可能更近。归属优先"|dy|≤15 且 片段x0−主值x1∈[-10,+20]"，欧氏作兜底（780674：±7.5 曾错挂 R10 TYP）。报告前检查公差语义通顺（"R10 TYP±7.5"这种组合即错挂）。
21. **底部标题栏截止分 x 区间**：全局 y 截止（页高-100）会把左下角视图标注（y>页高-100 但 x<标题栏左缘）当标题栏丢弃（780674：D 俯视图 22.5°/45°；780314：30°(y763)）。只对 "y0>页高-100 且 x0≥标题栏左缘-20"（标题栏左缘从底部 CJK 标签动态算）判标题栏；页底单字符数字判图框坐标格。
22. **英制分数尺寸碎化**：CAD 把分数拆成整数/分子/分母/英寸符 `"` 独立 span（`24 7/8`→`24`+` 7`+`8`），build_dim_table 旧版当多个独立主值 → 860404 尺寸表碎片化到 164 条、英制分数反向核销失效。必须用含 `merge_fractions()` 的脚本（英寸符确认 + 同行右侧/正下方双模式分母识别 + 整数正下方搜索），修复后 83 条 54 个分数合并、公制无回归。
23. **裸三角形(△/▽)被臆造为形位公差**：扫描件尺寸旁的孤立裸△无矩形框、无框内字母，GLM 反复误判"位置度△1/△38、平面度△6、平行度△4 1/2"（860404）。裸△是铸造/加工/指引标记，只有"矩形框内"才是 GD&T、"三角形内字母"才是基准。答案判"无形位公差框、无基准"。
24. **图案/阵列视图边界字母误读为基准**：花纹/阵列图四周的独立 A/B/C 是图案定义方向/范围标识（860404：图案视图 A 上边界、B 左右边界），分块读误报"基准 A/B"。独立字母、不在三角形内 → 写"无基准符号"。

## 6. 等价表达识别要点

- 客户独立尺寸 → 重绘"中心线+总长"对称表达（18 1/4 → 36 1/2 对称）
- 客户组合尺寸 → 重绘拆尺寸链（1 3/8 → 1 + 3/8）
- 客户十进制 → 重绘分数（0.75" → 3/4"）
- 客户文字深度 → 重绘截面尺寸（3/8 DEEP GROOVED → 3/8 深度）
- 客户典型(Tip.) → 重绘展开多处显式
- 客户跨视图重复表达 → 重绘集中单视图
- 度分 → 十进制换算（30°15' → 30°+0.25°）

## 8. 同值尺寸与局部视图完整性（860404 diff 提炼）

**同值尺寸必须按物理特征分别列出，禁止因数值相同而合并。**
案例（860404）：`1`(V1-D09 窄板宽) 和 `1`(V4-D25 板厚) 控制不同特征；`6`(V3-D08 槽高) 和 `6`(V3-D14 定位) 不同方向；`3 1/2`(V3-D11 槽宽) 和 `3 1/2`(V3-D18 边缘偏置) 不同端点。每个都要单独一行。

**局部放大视图（V5 类）不能遗漏**：即使局部放大图未作为重绘独立视图保留，其尺寸（如 1/8、R1/8）必须在合并视图中逐一核销，不能跳过整节。

**报告生成后必须做 ID 完整性核销**：统计报告的 ID 总数，与客户标注总数比对，缺项必须补回。

## 9. 参考属性判定口径

- **数值同、仅参考属性移除**：780673 判 Difference to note；780674 判 Confirmed error；**780672 判 Confirmed error**（254*→254、190*→190、5*→5、30*→30，数值同也判 error）。**共同点：必须识别并列出，不能漏**。倾向按"重绘是否明确标注该尺寸为参考"分：重绘无任何参考标记 → 该案例口径（780672/780674 为 Confirmed error，780673 为 Difference to note），重绘有参考意图但数值错 → Confirmed error。口径以各案例答案为准，核销时全部列出即可。
- **参考直径 omission**：客户参考直径重绘全无 = Confirmed omission，建议补回。
- **小数值差异**（Ø437.62 vs Ø437.6、239.8 vs 239.9）：参考尺寸变化 → Difference to note。
